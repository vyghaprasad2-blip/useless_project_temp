### Project Description
DELULU is a simple interactive web-based project designed to provide users with an engaging question-and-result experience. Users can answer questions through a web interface and view their results after completing the interaction

### The Problem (that doesn't exist)
People sometimes need a simple and entertaining way to test their choices, answers, or knowledge without complicated applications.
There is no serious problem here. We simply decided to use AI to investigate
the important questions nobody asked.

### The Solution (that nobody asked for)
DELULU uses the Groq AI API to analyze a user's thought or situation and
generate a humorous AI response. The application turns everyday overthinking
into an entertaining experience.

The app provides different personality/mode-based responses and helps users
decide whether their thought is REALITY or DELULU.
